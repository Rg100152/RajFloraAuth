## 📖 Overview

**RajFloraAuth** is a premium, immersive authentication portal with a unique floral theme. It features real-time sakura petal animations on a canvas background, interactive 3D tilt effects on cards and buttons, and complete signup/login functionality with local storage persistence.

### 🎯 Objectives
- **Immersive Experience:** Real-time petal animations and 3D interactions
- **Floral Theme:** Sakura-inspired design with purple accents
- **Dual Authentication:** Sign up and Sign in functionality
- **User Management:** LocalStorage for user database
- **Session Management:** Secure session storage
- **Personalized Dashboard:** Welcome message with user name
- **Interactive UI:** 3D tilt on cards and buttons

## ✨ Key Features

### 🔐 Authentication System
- **Sign Up:** Create new account with username and password
- **Sign In:** Login with existing credentials
- **Session Management:** Secure session storage
- **Logout:** Clear session and return to login
- **User Persistence:** LocalStorage for user database
- **Password Visibility Toggle:** Eye icon for password fields

### 🎨 Visual Design
- Deep purple gradient background with glowing orbs
- Real-time sakura petal animations on canvas
- Floating lock badge with pulse animation
- Purple gradient card header with avatar ring
- Pill-shaped input fields with icons
- Interactive 3D tilt on cards and buttons
- Click hand prompt icon on button

### 📊 Dashboard
- Personalized welcome message with flower emoji
- Floral Animation Engine widget
- 3D Interactive Space widget
- RajFloraAuth Secure DB widget

### 🔔 Notifications
- Toast notifications for all actions
- Color-coded feedback (success, error, info)
- Auto-dismiss after 3 seconds
